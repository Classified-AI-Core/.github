# Classified AI

We build private AI assistants and agent tooling for operators: founders, agencies, and small teams that want an assistant wired into their own data, tools, and workflows.

**Open source**

- [skill-library](https://github.com/Classified-AI-Core/skill-library): 207 agent skills for Claude Code and Zo Computer, MIT-licensed, screened for credentials and private paths before merge.
